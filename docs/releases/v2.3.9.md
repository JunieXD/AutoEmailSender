# v2.3.9

## 更新内容

### 新增功能

- 新增 macOS Apple Silicon 版安装包。
- 邮箱历史同步支持扫描收件箱和已发送文件夹的近两年往来记录。
- 其他设置新增意向研究方向，匹配分析会把它作为加分参考。

### 体验优化

- 首页导师看板和导师管理列表减少重复计算，大量导师时加载更快。
- 其他设置改为统一保存栏，长表单滚动时仍可直接保存。
- 邮箱历史同步会优先查找已联系导师的近期邮件，减少无关邮件扫描。
- 模型连接失败时会显示更明确的 TLS 或网络错误原因。

### 问题修复

- 修复数据库短暂锁定时桌面端启动可能失败。
- 修复部分数据库迁移重复执行时可能中断升级。
- 修复已发送邮件同步在邮箱 UID 变化后可能漏扫或重复扫描。
- 修复不同导师共用同一 Message-ID 时往来记录可能误合并。
- 修复发送后回查已发送邮件可能造成重复记录。
- 修复候选导师详情补全成功后仍显示旧失败日志。
- 修复部分导师职称没有从详情页补全的问题。

## 安装说明

- Windows：下载 `AutoEmailSender Setup 2.3.9.exe` 后双击安装。
- macOS Apple Silicon：下载 `AutoEmailSender-2.3.9-arm64.dmg`，打开后把应用拖到“应用程序”。
- macOS 首次打开若提示无法验证开发者，到“系统设置 > 隐私与安全性”点击“仍要打开”，再确认打开。
- Intel Mac 暂未提供安装包。
- 请只从本项目 GitHub Releases 页面下载安装包。

## 自动更新

- Windows：应用内可下载并安装更新。
- macOS Apple Silicon：应用内可检查更新；发现新版本后会打开 GitHub Releases，请下载新版 `.dmg` 并拖到“应用程序”覆盖安装。
