# v2.3.0

## 更新内容

### 新增功能

- 智能抓取升级为新的 V2 调度机制，抓取页面、拆分候选、补全导师信息会分阶段处理，长任务更容易稳定完成。
- 统计面板新增更完整的数据概览和可视化，可以查看导师匹配分布、Token 使用趋势和筛选后的任务统计。
- 智能抓取支持页面抓取账本，已处理过的页面会自动复用记录，减少重复抓取和重复消耗。
- 设置中新增智能抓取上下文预算和并发控制选项，可以更直接地控制抓取成本与运行速度。
- 首页导师列表支持按时间排序，回看最近更新或最近创建的导师更方便。
- 任务中心会显示智能抓取缓存命中的 Token 情况，成本来源更清楚。

### 体验优化

- 智能抓取在候选过多、页面较长或模型输出不稳定时会更稳地拆分和重试，减少任务卡住或提前结束的情况。
- 智能抓取会优先使用当前选中的模型启动后续运行，切换模型后再次抓取的行为更符合预期。
- 统计面板的筛选、图表层级和加载状态做了优化，切换条件时页面更稳定。
- Token 使用记录迁移到统计面板中统一查看，分析任务成本时不需要在多个入口之间切换。
- 草稿模板改写的提示词缓存更高效，重复使用相似模板时响应更顺畅。
- 邮件编辑器改进了 Markdown 快捷输入，编辑列表和格式化内容时更自然。
- 桌面端托盘增加诊断和退出入口，后台运行时排查问题和关闭应用更方便。
- 应用统一了时间处理方式，跨时区、重启后和不同页面之间显示的时间更一致。

### 问题修复

- 修复智能抓取暂停或终止后后台仍可能继续运行的问题。
- 修复智能抓取在空结果、无详情页候选、候选待审核等场景下状态不准确的问题。
- 修复智能抓取可能重复抓取反爬失败页面、列表页地址污染候选主页、同域名页面偏好不稳定等问题。
- 修复 V2 抓取任务中 URL 去重、Token 统计、任务恢复、失败预算和终态写入相关问题。
- 修复安装版环境下部分智能抓取流程不可用或行为不一致的问题。
- 修复模型切换后部分任务可见性不正确的问题。
- 修复统计筛选边界和导师管理页切换加载状态异常的问题。
- 修复抓取审核中可能导入无有效邮箱导师的问题。
- 修复部分接口时间序列化不一致导致前端显示或筛选异常的问题。
- 修复前端依赖配置不一致可能导致安装或构建异常的问题。

## 安装说明
