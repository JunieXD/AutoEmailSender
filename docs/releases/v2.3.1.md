# v2.3.1

### 新增功能

- 批量任务支持重新发起未成功项。
- 智能爬取支持从导师个人主页提取信息。
- 升级前自动备份本地数据库。

### 体验优化

- 数据版本不兼容时，会提示所需版本。
- 模型连接失败时，会显示更明确的错误原因。
- 桌面端升级后首次启动更稳定。
- 卸载时默认保留本地数据。

### 问题修复

- 修复定时发送时间显示偏移。
- 修复发送失败被显示为已联系。
- 修复无邮箱候选导致整批导入失败。
- 修复候选导师个人主页链接丢失。
- 修复数据库兼容版本记录错误。
- 修复卸载时数据清理选项失效。

## 安装说明

- 普通用户只需下载 `AutoEmailSender Setup 2.3.1.exe`。

## 自动更新

- 应用内会自动检查更新。
- 发现新版本后，可以选择增量下载或全量下载。
