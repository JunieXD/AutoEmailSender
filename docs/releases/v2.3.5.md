# v2.3.5

## 更新内容

### 新增功能

- 工作区导师档案会显示导师主页链接，桌面端可直接用系统浏览器打开。

### 体验优化

- Windows 后端打包移除不再需要的抓取依赖，安装包和差量更新体积更小。
- 默认模板编辑器改为提示通过“占位符”按钮插入个性化信息。
- 智能抓取继续保留浏览器抓取能力，并减少不必要的后端依赖。

### 问题修复

- 修复旧任务缺少申请材料时，工作区和匹配分析不能沿用当前身份默认材料的问题。
- 修复模板占位符插入后没有继承当前字体、字号或颜色的问题。
- 修复更新下载进度中差量包名称显示不一致的问题。

## 安装说明

- 普通用户只需下载 `AutoEmailSender Setup 2.3.5.exe`。

## 自动更新

- 应用内会自动检查更新。
- 发现新版本后，可以选择增量下载或全量下载。
