# v2.3.8

## 更新内容

### 新增功能

- 邮箱历史会自动同步已有导师相关的收件和已发送邮件。
- 工作区、首页状态和统计面板会统一显示系统发送和邮箱客户端发送的通信记录。
- 首页和导师管理页支持按字段切换升序或降序排序。
- 导师主页、来源链接和抓取候选链接支持直接打开。

### 体验优化

- 邮箱同步会优先处理新增邮件，历史补扫会分批执行并减少重复拉取。
- 邮箱服务商限流时会暂停高频历史补扫，避免反复触发失败。
- 首页、任务页和导师管理页切换后会保留页面状态和滚动位置。
- 关键词搜索范围支持先全部取消，再选择新的搜索字段。
- 候选导师补全会先提示已开始，完成后再显示最终结果。
- 差量更新不可用时，会明确提示已自动改用全量下载。

### 问题修复

- 修复定时批量任务在发送窗口尾部偶尔漏发。
- 修复 SMTP 发信后未同步保存到邮箱已发送记录。
- 修复已取消抓取任务可直接补全或审核导入候选导师。
- 修复候选导师补全成功后仍显示旧失败原因。
- 修复已停止、已完成或已过期的批量任务仍阻止删除材料。
- 修复邮箱同步在文件夹变化、重复邮件和密送记录场景下可能漏计或重复统计。

## 安装说明

- 普通用户只需下载 `AutoEmailSender Setup 2.3.8.exe`。

## 自动更新

- 应用内会自动检查更新。
- 发现新版本后，可以选择增量下载或全量下载。
