# v2.5.3

## 更新内容

### 新增功能

- 新增社区导师库，可按学校和学院浏览、筛选并批量导入公开导师资料；导入前可预览本地差异并处理冲突。
- 任务中心新增发送计划，可集中查看即将发送、需处理和历史邮件，并支持改期、取消、恢复或立即发送。
- Windows 和 Apple 芯片 Mac 桌面版新增命令行与 Agent 支持，可自动识别并接入 Codex 等本地 Agent；真实发送仍需用户明确确认。
- 批量任务支持一键批准待审核的 AI 草稿，也可单独取消或恢复某位导师的发送。
- 智能抓取候选审核新增关键词、审核状态和资料完整度组合筛选。
- 数据看板新增院校回复率对比，导师列表支持按匹配分数范围筛选。

### 体验优化

- 导师缺少研究方向时，批量任务可改用模板生成草稿；添加较大附件时会提前提示文件大小风险。
- 批量任务重新发起未成功项时，会优先沿用上次已审核或已生成的草稿。
- 长列表和大型任务详情优化分页与布局，切换筛选、翻页和批量选择更顺畅。
- 多个后台任务并行时，草稿生成、匹配分析和智能抓取的进度更新更及时稳定。

### 问题修复

- 修复 Windows 卸载应用时，已安装的命令行与 Agent Skill 可能未能正常清理的问题。
- 修复部分动态导师目录或个人主页加载较慢时，抓取过早结束并遗漏导师或资料的问题。
- 修复部分学校网站证书过期时无法继续抓取公开页面的问题。
- 修复同一导师可能重复出现在候选列表，以及可导入数量误计入无邮箱候选的问题。
- 修复社区导师库在系统代理变更后，或打开研究所下属中心数据时可能加载失败的问题。
- 修复 Windows 启用命令行与 Agent 支持后，当前应用仍可能找不到新命令的问题。
- 修复邮箱同步任务切换或重启后，旧任务仍可能继续运行并覆盖新状态的问题。
- 修复部分设备连接邮件服务器时发送失败的问题，错误原因现在更明确。
- 修复接近午夜时任务名称和统计日期可能偏移的问题。

## 安装说明

- Windows：下载 `AutoEmailSender-Setup-2.5.3.exe` 后双击安装。
- macOS Apple Silicon：下载 `AutoEmailSender-2.5.3-arm64.dmg`，打开后把应用拖到“应用程序”。
- macOS 版本尚未通过 Apple 官方认证，首次打开可能会被系统拦截；请到“系统设置 > 隐私与安全性”点击“仍要打开”，再确认打开。
- Intel Mac 暂未提供安装包。

## 自动更新

- Windows：支持在应用内下载并安装更新。
- macOS Apple Silicon：支持自动检查并在应用内安装更新。
- 旧版 macOS 用户需要手动安装本版本一次，之后即可使用应用内更新。
