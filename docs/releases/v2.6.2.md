# v2.6.2

### 新增功能

- 删除身份配置和模型配置前会显示关联影响；正在执行的操作会阻止删除，其他未完成任务会按提示安全停止。
- 发信模板改为归档，可在模板库中恢复；删除材料前会显示当前使用情况。

### 体验优化

- 邮件计划会标明“发件身份已删除”“模型配置已删除”等未发送原因，并支持直接查看已移入回收站的导师。
- 统一居中弹窗的样式与交互，删除确认和任务操作更易辨认。
- Windows 安装或更新会跳过已安装的 Visual C++ 运行库；确需安装时会先提示 UAC 授权。

### 问题修复

- 修复删除身份或模型配置时历史任务、通信记录、材料和分析结果可能被一并移除的问题；邮箱密码和 API Key 仍会安全清除。
- 修复部分学校页面通过脚本打开导师主页时无法识别链接的问题，并改善公开导师主页域名解析失败后的重试。

## 安装说明

- Windows：下载 `AutoEmailSender-Setup-2.6.2.exe` 后双击安装。
- macOS Apple Silicon：下载 `AutoEmailSender-2.6.2-arm64.dmg`，打开后把应用拖到“应用程序”。
- macOS 版本尚未通过 Apple 官方认证，首次打开可能会被系统拦截；请到“系统设置 > 隐私与安全性”点击“仍要打开”，再确认打开。
