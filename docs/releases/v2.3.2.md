# v2.3.2

## 更新内容

### 新增功能

- 导师支持添加、编辑和删除标签，并可在首页和导师管理页按标签筛选。
- 导入导师时支持同时导入标签，并会在导入结果中显示新建标签数量。
- 关键词搜索支持选择搜索字段，可限定姓名、学校、学院、系所、职称、研究方向、邮箱或标签。

### 体验优化

- 首页和导师管理页会直接显示导师标签，标签过多时可展开查看。
- 搜索框占位文案会根据已选搜索字段同步变化。
- Linux 桌面端开发环境关闭窗口时会直接退出，减少后台进程残留。
- Linux 桌面端会使用适配的窗口图标。

### 问题修复

- 修复导师联系状态在新任务生成后可能被误判为未联系或待发送。
- 修复草稿生成中断后任务可能长时间停留在生成中的问题。
- 修复旧版本数据库升级时部分迁移步骤容错不足的问题。
- 修复首页导师标签可被拖动的问题。
- 修复没有标签的导师仍显示空标签占位文案的问题。

## 安装说明

- 普通用户只需下载 `AutoEmailSender Setup 2.3.2.exe`。

## 自动更新

- 应用内会自动检查更新。
- 发现新版本后，可以选择增量下载或全量下载。
