# v2.6.0

## 更新内容

### 新增功能

- 导师列表新增邮箱搜索、分页浏览和批量标签操作，适合管理更大规模的导师资料。
- 材料库现在可在不同任务和工作区之间复用，批量任务支持更完整的草稿审核与处理流程。
- Agent 与命令行支持更多桌面工作区操作，可从自动化流程安全地跳转到对应界面继续处理。

### 体验优化

- 智能抓取会重试受限目录、复用有效的浏览器挑战状态，并支持从个人主页和嵌入式资料中继续补全信息。
- 后台任务中心支持更清晰的筛选、排序和页面状态保留，切换任务或返回页面时不易丢失当前位置。
- 应用启动更快、运行时占用更低；批量发送、社区导师和工作区列表的加载与滚动更稳定。

### 问题修复

- 修复部分学校目录因页面跳转、嵌套分类或浏览器状态变化而遗漏导师或重复抓取的问题。
- 修复邮件同步可能产生重复记录、定时发送状态显示不准确，以及批量草稿取消或重新应用模板后状态未正确保存的问题。
- 修复桌面工作区、导师筛选和资料补全中的若干空状态、选择提示和滚动恢复问题。

## 安装说明

- Windows：下载 `AutoEmailSender-Setup-2.6.0.exe` 后双击安装。
- macOS Apple Silicon：下载 `AutoEmailSender-2.6.0-arm64.dmg`，打开后把应用拖到“应用程序”。
- macOS 版本尚未通过 Apple 官方认证，首次打开可能会被系统拦截；请到“系统设置 > 隐私与安全性”点击“仍要打开”，再确认打开。
- Intel Mac 暂未提供安装包。

## 自动更新

- Windows：支持在应用内下载并安装更新。
- macOS Apple Silicon：支持自动检查并在应用内安装更新。
- 旧版 macOS 用户需要手动安装本版本一次，之后即可使用应用内更新。
