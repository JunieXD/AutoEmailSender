# v2.6.4

### 新增功能

- Agent CLI 支持按操作意图获取命令用法，并根据任务结果继续等待、翻页或恢复导出。

### 体验优化

- 优化批量草稿审核队列布局，收起写信区后工作区不再留出大片空白。
- 导师抓取 Skill 可独立生成和校验表格，更清楚地指出待修正的信息与来源问题。

### 问题修复

- 修复批量审核时切换草稿或关闭详情导致编辑内容丢失；保存失败时保留当前草稿并提示重试。
- 修复定时邮件改期、取消和立即发送时误报状态冲突，以及详情弹窗反复打开的问题。
- 修复 Agent CLI 部分输入、等待超时和结果恢复异常，导出失败时保留已有文件。

## 安装说明

- Windows：下载 `AutoEmailSender-Setup-2.6.4.exe` 后双击安装。
- macOS Apple Silicon：下载 `AutoEmailSender-2.6.4-arm64.dmg`，打开后把应用拖到“应用程序”。
- macOS 版本尚未通过 Apple 官方认证，首次打开可能会被系统拦截；请到“系统设置 > 隐私与安全性”点击“仍要打开”，再确认打开。
