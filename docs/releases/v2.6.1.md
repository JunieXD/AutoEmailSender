# v2.6.1

## 更新内容

### 新增功能

- 导师列表支持按备注搜索，可以快速找到加过备注的导师。
- 任务中心实时日志会显示资料补全进度，补全进行到哪一步一目了然。

### 体验优化

- 任务中心以及抓取、补全列表改为分页加载，打开更快、滚动更流畅。
- 导师管理、批量任务、材料库和社区导师列表减少不必要的数据传输，加载明显提速。
- 智能抓取减少重复的浏览器请求，更省流量。
- 悬停被截断的文本即可查看完整内容。
- 升级桌面内核与相关依赖，运行更稳定。

### 问题修复

- 修复安装自动更新时应用可能提前退出、导致更新没有完成的问题。
- 修复部分学校目录因访问受限、嵌套分类或分页变化而抓取中断或遗漏导师的问题，可恢复的失败会自动重试。
- 修复导师个人主页无法访问时，已有邮箱被误判为变更而重复处理的问题。
- 修复部分模型因接口变化导致检测或调用失败的问题。
- 修复后台任务偶尔没有出现在任务中心、补全进度显示不准确的问题。

## 安装说明

- Windows：下载 `AutoEmailSender-Setup-2.6.1.exe` 后双击安装。
- macOS Apple Silicon：下载 `AutoEmailSender-2.6.1-arm64.dmg`，打开后把应用拖到“应用程序”。
- macOS 版本尚未通过 Apple 官方认证，首次打开可能会被系统拦截；请到“系统设置 > 隐私与安全性”点击“仍要打开”，再确认打开。
