# 导师个人备注设计

## 背景

用户希望给每位导师记录自由备注，例如面试时间、回复态度、后续补材料事项等。现有首页导师看板和导师管理页已经承担筛选、标签、匹配度、状态、操作按钮等信息，不能再把备注正文直接塞进列表，否则会继续挤压主要流程。

本设计把备注定位为“用户自己的私人记录”。列表只提示“这位导师有备注”，完整内容通过悬浮浮层和编辑弹窗访问。

## 目标

- 导师管理页的完整编辑弹窗支持填写和保存个人备注。
- 首页导师列表和导师管理页列表在导师有备注时显示一个小备注图标。
- 鼠标悬浮或键盘聚焦备注图标时显示完整备注内容。
- 点击备注图标打开只编辑备注的小弹窗。
- 清空备注并保存后，该导师在首页和导师管理页列表中的备注图标立即消失。
- 备注不参与邮件生成、AI 改写、匹配分析、筛选、任务状态判断或导师公开资料展示。

## 非目标

- 不做提醒、日历、通知或待办系统。
- 没有备注的导师不在列表显示“新增备注”入口；新增备注从导师管理页的完整编辑弹窗进入。
- 不新增导师管理列表列，也不在列表常驻展示备注摘要。
- 第一版不把备注加入导入模板或普通导师导出，避免误分享私人记录；“包含个人备注的导出”不属于本次范围。
- 不在工作区侧栏、创建任务页或邮件正文预览中展示备注。

## 用户体验

### 列表备注图标

首页导师列表和导师管理页列表都在导师姓名旁显示备注图标，顺序为：

```text
导师姓名  [备注图标]  [标签]
```

显示规则：

- `personal_note` 去掉前后空白后为空：不显示图标。
- `personal_note` 有内容：显示一个小图标，例如 lucide 的 `StickyNote` 或 `NotebookText`。
- 图标使用克制颜色，例如石色或浅琥珀色，不抢过标签和联系状态。
- 图标是按钮，点击时只打开备注编辑弹窗，不触发行选择、打开工作区或导师完整编辑。

### 悬浮完整备注

有备注图标的导师支持 hover / focus 查看完整备注：

- 使用自定义浮层，不依赖浏览器原生 `title`。
- 浮层显示完整备注，保留换行。
- 最大宽度约 `360px`，最大高度约 `240px`，超长内容内部滚动。
- 浮层不改变列表行高，不把周围内容挤开。
- 键盘聚焦图标时也能显示，保证基本可访问性。

### 备注专用编辑弹窗

点击列表备注图标打开轻量弹窗，仅用于编辑该导师的个人备注：

- 标题：`编辑个人备注`
- 上方显示导师姓名和学校 / 学院作为上下文。
- 主体是多行 textarea，默认填入当前备注。
- 操作：`保存`、`取消`。
- 保存期间禁用保存按钮，避免重复提交。
- 保存成功后关闭弹窗，并立即更新当前列表行。
- 清空 textarea 并保存后，后端保存为空值，列表备注图标消失。

### 完整导师编辑弹窗

导师管理页点击“编辑”打开的完整导师表单增加“个人备注”区域：

- 位置放在研究方向 / 近期论文之后，资料来源字段之前。
- 使用多行 textarea，初始高度约 5-6 行。
- 文案说明保持简短，强调这是个人记录。
- 示例 placeholder：

```text
例如：6 月 20 日上午 Zoom 面试；导师回复很积极；后续需要补发成绩单。
```

## 数据模型

在 `professors` 表增加字段：

```text
personal_note TEXT NULL
```

规则：

- 后端保存前 trim 前后空白。
- trim 后为空时保存为 `NULL`。
- 不做富文本，只保存纯文本。
- 不限制行数；后端设置 10,000 字符上限，防止误粘贴超大内容。
- 操作日志记录备注是否存在和长度，不记录备注正文，避免把私人记录写入日志。

## API 设计

### DTO

以下响应增加 `personal_note: str | None`：

- `ProfessorRead`
- `ProfessorDashboardItemRead`
- `ProfessorManagementItemRead`

前端对应类型增加 `personal_note: string | null`：

- `ProfessorDTO`
- `ProfessorDashboardItemDTO`
- `ProfessorManagementItemDTO`

### 完整导师保存

`ProfessorUpsertPayload` 增加：

```text
personal_note: str | None = None
```

创建和编辑导师时随完整表单一起保存。

### 专用备注更新接口

新增接口：

```http
PATCH /api/professors/{professor_id}/note
```

请求体：

```json
{
  "personal_note": "6 月 20 日上午 Zoom 面试"
}
```

响应返回：

```json
{
  "id": 1,
  "personal_note": "6 月 20 日上午 Zoom 面试"
}
```

前端收到响应后只更新当前导师条目的 `personal_note`，不覆盖其他导师字段。

错误处理：

- 找不到导师：`404`
- 备注过长或格式不合法：`400`
- 其他保存失败：常规 API 错误

## 前端结构

### 共享组件

新增一个共享的备注按钮组件，例如 `ProfessorNoteButton`：

- 输入：`professorName`、`personalNote`、`onEdit`
- 为空备注时返回 `null`
- 内部处理 hover/focus 浮层
- 点击按钮调用 `onEdit`

新增一个共享的备注编辑弹窗，例如 `ProfessorNoteDialog`：

- 输入：`open`、`professor`、`initialNote`、`saving`、`onSave`、`onClose`
- 内部管理 textarea 草稿
- 保存时把 textarea 内容传给调用方

### 首页导师行

`DashboardProfessorRow` 在姓名和标签之间渲染备注按钮：

- `personal_note` 有内容时显示。
- 点击后通知 `HomePage` 打开备注编辑弹窗。
- 保存成功后只更新当前导师的 `personal_note`，不重新加载整个列表。

### 导师管理行

`ManagementProfessorRow` 同样在姓名和标签之间渲染备注按钮：

- 点击后打开备注专用弹窗。
- “编辑”按钮仍然打开完整导师编辑表单。

### 导师管理完整表单

`ProfessorsPage` 的 `ProfessorFormState`、`toProfessorForm`、`toProfessorPayload` 增加 `personal_note`。

编辑导师时，完整表单中的备注字段随导师资料一起保存。保存成功后更新当前导师条目的 `personal_note`。

## 状态同步

首页和导师管理页各自维护当前页面的导师数组。备注保存成功后：

- 使用返回数据或响应中的 `personal_note` 更新数组中对应导师。
- 如果新备注为空，组件因 `personal_note` 为空而不再渲染图标。
- 如果保存失败，弹窗保持打开，列表仍显示旧备注。

## 隐私与边界

- LLM prompt 构造、邮件模板变量、匹配分析上下文不读取 `personal_note`。
- 关键词搜索范围不包含 `personal_note`。
- 标签、状态、匹配度排序不受备注影响。
- 操作日志不记录备注正文。
- 普通导出和导入模板暂不包含个人备注。

## 测试计划

### 后端

- 迁移测试或模型测试覆盖 `personal_note` 字段存在。
- `ProfessorUpsertPayload` 接受备注，空白备注归一化为空。
- `ProfessorDashboardItemRead` 和 `ProfessorManagementItemRead` 序列化包含备注。
- `PATCH /api/professors/{id}/note` 能保存备注。
- `PATCH /api/professors/{id}/note` 传空字符串后清空备注。
- 操作日志不包含备注正文。

### 前端

- `DashboardProfessorRow`：有备注时显示备注图标，无备注时不显示。
- `ManagementProfessorRow`：有备注时显示备注图标，无备注时不显示。
- 备注图标 hover / focus 展示完整备注文本。
- 点击备注图标打开备注专用弹窗。
- 备注专用弹窗保存后更新当前行备注。
- 清空备注保存后图标消失。
- 完整导师编辑弹窗能编辑并提交 `personal_note`。
- 现有筛选、标签显示和行选择行为不因备注图标回归。

## 验收标准

- 用户能在导师管理页完整编辑弹窗中新增备注。
- 有备注的导师在首页和导师管理页列表中显示小备注图标。
- 鼠标悬浮备注图标能看到完整备注内容，长备注不会撑开列表。
- 点击备注图标能打开只编辑备注的小弹窗。
- 清空备注并保存后，首页和导师管理页列表不再显示该导师备注图标。
- 备注不会出现在邮件生成、AI 改写、匹配分析、筛选和普通导出中。
