# 导师标签功能设计

## 背景

导师库目前主要依赖姓名、邮箱、学校、学院、职称、研究方向、匹配度和发送状态来组织数据。用户还需要记录人工判断，例如“高意愿”“低意愿”“羊导”等。这类信息不适合塞进研究方向或备注字段，应该成为可展示、可编辑、可筛选的结构化标签。

## 目标

- 支持为每位导师添加多个标签。
- 所有导师默认无标签，展示为“暂无标签”。
- 提供初始标签候选：已退休、高意愿、低意愿、羊导、高强度。
- 支持创建自定义标签，包含标签名、字体颜色和背景颜色。
- 支持删除任意真实标签；删除时同步从所有导师身上移除。
- 首页、导师管理页、编辑导师弹窗都展示或编辑标签。
- 首页和导师管理页支持按标签搜索和筛选。

## 非目标

- 第一版不支持批量导入标签。
- 第一版不支持标签分组、排序配置或权限控制。
- 第一版不把“暂无标签”存成真实标签。
- 第一版不支持按“同时拥有所有选中标签”筛选，只支持命中任一选中标签。

## 数据模型

新增 `professor_tags` 表：

- `id`
- `name`
- `text_color`
- `background_color`
- `created_at`
- `updated_at`

新增 `professor_tag_links` 表：

- `professor_id`
- `tag_id`
- `created_at`

规则：

- `name` 去除首尾空格后唯一。
- 一个导师可以关联多个标签。
- 一个标签可以关联多个导师。
- 老师没有任何标签时，前端展示“暂无标签”。
- “暂无标签”是虚拟状态，不写入数据库。
- `+ 自定义标签` 是操作入口，不写入数据库，不参与筛选，不能删除。
- 删除标签时，后端在同一事务内删除标签候选和所有导师关联。

## 默认标签

迁移时插入以下默认标签：

- 已退休
- 高意愿
- 低意愿
- 羊导
- 高强度

迁移必须幂等。重复启动或重复执行迁移时，不应重复插入同名标签。

默认标签也是普通真实标签。用户可以删除它们，删除后会从所有导师身上移除。

## API 设计

新增或扩展接口：

- `GET /api/professors/tags`
  - 返回所有标签候选。
- `POST /api/professors/tags`
  - 创建自定义标签。
  - payload 包含 `name`、`text_color`、`background_color`。
  - 标签名重复时返回明确错误。
- `DELETE /api/professors/tags/{tag_id}`
  - 删除标签候选。
  - 同步删除所有导师和该标签的关联。
- 现有创建导师接口
  - payload 增加 `tag_ids`。
  - 创建导师后写入标签关联。
- 现有更新导师接口
  - payload 增加 `tag_ids`。
  - 更新导师信息时替换该导师的标签关联。

首页和导师管理列表 DTO 增加 `tags` 数组。每个标签包含：

- `id`
- `name`
- `text_color`
- `background_color`

如果创建或更新导师时传入不存在、已删除或重复的标签 id，后端返回明确错误，不静默忽略。

## 首页展示

首页导师列表在导师姓名后展示标签胶囊。

展示规则：

- 无标签时显示低强调胶囊“暂无标签”。
- 有标签时最多显示前 3 个真实标签。
- 超过 3 个时显示 `+N` 胶囊。
- 点击或悬浮 `+N` 可查看完整标签列表。
- 标签过多时不自动换行成多列，不把整行高度无限撑开。
- 标签胶囊使用标签自定义字体色和背景色，形态为圆角矩形。

标签展示优先保持列表可扫描。标签不是首页行的主状态字段，不替代匹配度、发送次数或任务状态胶囊。

## 导师管理页展示

导师管理页不新增独立标签列，避免表格继续拥挤。

标签放在姓名单元格内：

- 第一行：姓名和已删除状态。
- 第二行：标签摘要。

展示规则：

- 无标签显示“暂无标签”。
- 有标签时最多显示前 2 个真实标签。
- 超出部分显示 `+N`。
- 移动端沿用姓名块内展示，不新增横向滚动压力。

## 新增和编辑导师

新增或编辑导师弹窗增加“导师标签”区域。

交互规则：

- 默认状态为“暂无标签”。
- 展示所有标签候选。
- 点击标签即可选中或取消。
- 一个导师可以选中多个标签。
- 已选标签需要有清晰的选中状态。
- 提供 `+ 自定义标签` 按钮。

创建自定义标签时，用户填写：

- 标签名
- 字体颜色
- 背景颜色

创建成功后：

- 新标签进入标签候选库。
- 新标签默认自动选中到当前正在编辑的导师。

删除标签时：

- 每个真实标签都可以删除。
- `+ 自定义标签` 不显示删除入口。
- 删除前弹出确认，说明会从所有导师身上移除该标签。
- 删除成功后，候选列表、当前编辑导师的选中标签、首页展示、管理页展示和筛选选项都同步更新。

## 关键词搜索

首页和导师管理页的关键词搜索范围增加“标签”字段。

规则：

- 搜索范围包含“标签”时，关键词会匹配导师已绑定标签的名称。
- 搜索范围不包含“标签”时，关键词不会匹配标签名。
- 无标签导师不会因为关键词包含“暂无标签”而命中。
- 关键词搜索范围继续保持至少选择一项的规则。

推荐默认值：

- 新增“标签”后，默认搜索范围包含标签。
- 这样用户输入“高意愿”等标签名时可以直接命中导师。

## 标签筛选

首页和导师管理页的高级筛选增加独立“标签筛选”。

筛选选项：

- 所有真实标签候选。
- 虚拟选项“暂无标签”。

不包含：

- `+ 自定义标签`。

默认状态：

- 默认全部勾选，表示不过滤标签。

筛选规则：

- 多标签导师只要命中任一已选真实标签，就保留。
- 勾选“暂无标签”时，无标签导师保留。
- 未勾选“暂无标签”时，无标签导师被过滤掉。
- 至少保留一个标签筛选项。
- 如果用户试图取消最后一个选项，提示“至少选择一个标签”。
- 删除某个标签候选后，该标签从筛选选项和当前筛选状态中移除。
- 如果删除后筛选状态为空，回退为全部勾选。

## 导入和导出

第一版导入模板不增加标签列，避免引入“自动创建标签”或“只匹配已有标签”的额外规则。

导出增加 `tags` 列：

- 用中文分号拼接导师标签名。
- 无标签时导出为空。
- 导出的 `tags` 列仅用于查看和备份。
- 第一版再次导入该文件时忽略 `tags` 列。

## 颜色规则

自定义标签必须保存字体颜色和背景颜色。

前端应提供颜色输入或预设色板。保存前应校验颜色值是合法 CSS hex 颜色，例如 `#166534`。

为了可读性，前端可以在创建时提示低对比度颜色，但第一版不强制自动调整颜色。

## 错误处理

- 创建标签名为空：阻止提交并提示。
- 创建标签名重复：后端返回错误，前端提示标签已存在。
- 删除不存在的标签：返回明确错误。
- 更新导师时包含不存在的标签 id：返回明确错误。
- 标签列表加载失败：编辑区显示错误状态，不阻断导师基础信息查看。
- 标签保存失败：导师保存失败，并保留弹窗内当前输入状态。

## 测试计划

后端测试：

- 迁移会创建默认标签，并且重复执行不会重复插入。
- 创建自定义标签会保存名称和颜色。
- 重复标签名会被拒绝。
- 更新导师可绑定多个标签。
- 删除标签会删除所有导师关联。
- 首页列表 DTO 返回标签数组。
- 管理列表 DTO 返回标签数组。

前端测试：

- 标签胶囊展示无标签状态。
- 标签胶囊最多展示固定数量并显示 `+N`。
- 编辑弹窗可以选择多个标签。
- 创建自定义标签后自动选中。
- 删除标签确认后从候选和当前导师已选中移除。
- 关键词搜索范围包含标签时可按标签名命中。
- 标签筛选包含真实标签和“暂无标签”。
- 标签筛选至少保留一项。
- 删除标签后筛选状态自动清理。

## 实现边界

这个功能横跨后端数据库、API、前端类型、列表展示、编辑弹窗和筛选逻辑。实现时应拆成小任务：

1. 后端模型、迁移和标签 API。
2. 教授 DTO 和创建/更新接口接入标签。
3. 前端类型、API client 和共享标签胶囊组件。
4. 编辑弹窗标签选择和自定义标签管理。
5. 首页和导师管理页展示标签。
6. 首页和管理页关键词搜索与标签筛选。
7. 导出 `tags` 列。

每一步都应有聚焦测试，避免一次性大改导致回归难定位。
