# 首页空字段行隐藏设计

## 背景

导师管理页需要将整格空字段显示为“无”，让用户可以理解并使用“无”搜索空字段。首页列表不适合展示占位文本：当摘要信息或研究方向为空时，应保持原有的紧凑布局，不显示对应行。

## 范围

- 仅修改首页 `DashboardProfessorRow` 的展示。
- 姓名下方的“职称 / 学校 / 学院”组合文本为空时，不渲染该行。
- 研究方向为空时，不渲染该行。
- 组合字段任意一项有非空文本时，仍仅显示已有项并用 ` / ` 分隔。
- 导师管理页继续将整格空字段显示为“无”。
- 首页与导师管理页继续共用空字段搜索 helper；首页输入“无”仍可筛选到相应字段为空的导师。

## 实现

`DashboardProfessorRow` 先计算组合摘要文本，并使用共享的 `isProfessorSearchFieldEmpty` 判断其是否为空。组合摘要和研究方向分别进行条件渲染；非空时只输出原有文本与样式，不再调用会返回“无”的展示格式化函数。

`filterDashboardProfessors` 和 `professorSearchField` 的搜索匹配逻辑不修改，避免显示策略影响筛选语义。

## 测试

- 组合摘要和研究方向均为空时，首页不出现“无”，且两行节点不渲染。
- 组合字段部分存在值时，首页显示现有内容和正确分隔符。
- 既有首页筛选测试继续覆盖输入“无”匹配空字段。
- 运行前端测试、lint 和生产构建。
