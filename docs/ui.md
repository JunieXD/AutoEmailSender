# 界面

界面的结构、交互和样式。功能见[总体设计](design.md)，实现上的约定见[开发约定](development.md#界面)。

## 布局

- 电脑：左边是侧边栏，右边是一张圆角的内容页。侧边栏从上到下是品牌、导航（导师、往来、任务、找导师、统计）、[后台](#后台)入口和账号，设置从账号进。
- 手机：底部四个标签：导师、往来、任务、更多。"更多"里是找导师、统计、设置和后台。
- 按窗口的宽度切换布局，不判断设备类型：

| 宽度 | 变化 |
|---|---|
| ≤ 1240px | 审核草稿不显示右侧的匹配结果，导师表格不显示标签列 |
| 约 1050px 以下 | 导师表格放不下各列，每行变成卡片 |
| ≤ 760px | 手机布局：底部标签栏；往来和审核草稿分成列表和详情两级，详情左上角返回；次要操作收起 |

## 页面

| 页面 | 结构 |
|---|---|
| 导师 | 首页。上面是搜索、"添加导师"菜单（智能抓取、从导师库添加、导入表格、手动添加）、联系状态分段和筛选条件；下面是分页的导师表格：导师、学校和学院、研究方向、匹配度、联系、标签。勾选后底部浮出批量操作条：写信、分析匹配度、添加标签、移入回收站 |
| 导师详情 | 点导师进入，一位导师的资料、匹配结果和往来都在这一页。中间是往来；还没联系过的，中间是写首封的编辑框（AI 起草、使用模板、定时发送）。右边是资料、标签、匹配度和理由、契合方向、建议强调、风险、代表论文和备注。手机上右边的内容收进顶部的"资料"。顶部右边是"移入回收站"；在回收站里的导师，顶部说明这一点，可以恢复或永久删除 |
| 回收站 | 从导师列表底部的"回收站"进入。表格和导师列表相同，最近移入的在前；勾选后批量操作条是恢复和永久删除。点导师进入导师详情 |
| 往来 | 左边是会话列表，分全部、新回信、待办；右边是和一位导师的往来（见[处理回信](design.md#处理回信)）：自己的信在右、导师的在左，引用的原信折叠，待办跟在回信后面，底部是回复框。顶部的"资料"进入导师详情 |
| 任务 | 分任务和发送计划两个标签。任务列表的每一项用一条分段条显示各状态的邮件数。进入任务审核草稿：左边是草稿列表，标出状态和问题数；中间是收件人、主题、发送前检查的问题、正文和附件；右边是匹配结果。底部是移出任务、重新生成、AI 改写和"批准并查看下一封"。发送计划分待处理、即将发送、历史 |
| 新建任务 | 弹窗，三步：导师、撰写方式（AI 逐一撰写或使用模板，选参考材料和附件）、发送时间（审核后立即发送或定时发送）。选中的导师里有已联系过的，提醒并可以移出 |
| 找导师 | 三个标签：候选（逐个接受、合并或拒绝，标出疑似重复和缺失的字段，资料不全的可以补全）；智能抓取（输入学院官网地址开始，下面是抓取记录）；导师库（左边选学校和学院，右边勾选导师，底部显示今天还能添加多少位） |
| 统计 | 右上角选时间范围。联系进度：已联系、已回复、平均首次回复时间、退信四个数字，每日发出、首次回复等待时间两张图和院校对比表。导师：匹配度分布、学校、资料完整度。Token 用量：按用途和官方模型额度 |
| 设置 | 从侧边栏底部的账号进入。左边是分组导航：个人（个人资料、材料、模板、信件样式）、邮件（邮箱、发送前检查、回信处理）、AI（模型）、应用（外观、通知、备份、手机和 Agent、账号和赞助、关于和日志）。手机上先列出分组，点进去再看内容 |
| 启动失败 | 数据库打不开或升级失败时代替整个应用显示：说明原因，升级失败的写明升级前的备份在哪里，下面是"导出日志" |
| 首次引导 | 第一次打开时的引导卡片，按[首次引导](design.md#个人资料和配置)的顺序一步一步来，每步都能跳过，之后在设置里改。填邮箱时自动识别服务商、填好服务器，并说明要用授权码登录 |

## 后台

匹配分析、智能抓取、生成草稿、定时发送和收信在后台进行，用户随时能看到它们在做什么、有没有出问题。

- 侧边栏底部常驻后台入口：有工作在进行时转圈并显示数量，有待处理的事显示黄色数字。点开是面板：

| 分组 | 内容 |
|---|---|
| 待处理 | 失败的工作、因限流暂停的邮箱，可以重试或查看 |
| 进行中 | 匹配分析、智能抓取、生成草稿，显示进度，可以暂停 |
| 按计划进行 | 定时发送的下一封和今天还剩几封、最近一次收信，可以暂停或立即收信 |
| 今天完成 | 做完的工作和结果，比如抓到多少位候选，可以直接去审核 |

- 面板里每一项都能跳到结果所在的页面，进度也显示在那里：导师列表顶部的匹配进度、匹配度一栏的"分析中"和"排队中"、草稿列表里的"生成中"。
- 做完一项工作时，应用在前台就在内容页左下角弹出提醒，不在前台就发系统通知（可以关）。
- 手机上后台面板在"更多"里；有待处理的事时，"更多"标签上亮黄点。

## 交互

- 红点和红色数字只表示新回信（规则见[处理回信](design.md#处理回信)）；后台待处理的事用黄色。
- 列表里的行、会话和草稿各是一个圆角块，相邻的留 3px 间隙，连续选中的也不连成一片。
- 菜单和面板：点外面或按 Esc 关闭，焦点回到打开它的按钮。有未保存内容的弹窗不这样关（见[开发约定](development.md#界面)）。
- AI 改出来的内容先显示对比：删掉的划线，新加的标绿，AI 自己加上的日期、数字这类事实标黄并提示核对。用户确认后才替换。
- 发送前检查的问题标在正文里对应的文字上，问题旁边有一键修复。
- 标签：导师详情的"标签"旁点"编辑"，弹出所有标签逐个勾选，下面的输入框按回车新建并直接加上，新标签按预设颜色依次取色。"管理标签"里改名、换颜色、调顺序和删除，删除要再点一次确认；标签在各处都按这里的顺序排。
- 勾选：表格每行前面有复选框，表头的复选框勾选或取消本页全部。翻页保留勾选，换联系状态或关键词时清空。批量操作条浮在内容页底部中间：取消选择、已选几位和操作。
- 移入回收站和永久删除先弹出确认，说清后果：移入回收站时没发出的邮件会取消，恢复后也不会恢复；永久删除不能撤销。
- 批量操作条上的"写信"：选了一位导师时进入导师详情，选了多位时打开新建任务。
- 图表：悬停（手机上点按）显示数值；每张图都能切换成表格查看。
- 快捷键：⌘K（Windows 上是 Ctrl+K）搜索导师；审核草稿时 A 批准，J 和 K 切换；回复框里 ⌘Enter（Ctrl+Enter）发送。
- 空的页面告诉用户下一步做什么；出错时说清发生了什么、该怎么办。

## 文案

简明、书面、平实：普通学生一读就懂，语气正式但不生硬。这些规则只管界面自己的文字；用户起的标签、任务名和备注照用户的写法，示例数据也按学生的习惯写，比如标签"梦导"。

- 用书面词，不用口语：写"未、已、尚未、可、无需、待"，不写"没、还没、好了、接着、就、吧"；也不用"进行、予以、操作成功"这类公文腔。
- 一句只说一件事。先说结果或现状，再说原因和下一步，比如"已暂停发信：被服务商限流，预计明天 0:00 恢复"。
- 称呼用户用"你"，和 macOS、Windows 的中文界面一致；能省略主语就省略。
- 按钮和菜单项用动词或动宾短语，说清点了会怎样，比如"批准并查看下一封""添加邮箱"。同一个操作在按钮、提示和记录里用同一个词。
- 状态用"已……""未……""待……""……中"：已发出、未联系、待审核、生成中。
- 出错时说清发生了什么、该怎么办；不道歉，不用感叹号。
- 数字用阿拉伯数字并带量词：3 位导师、12 封。日期写"10月24日"，时间写"09:30"。
- 标点用全角，提到界面上的名称时加引号。按钮、标签、标题和只有一句的说明末尾不加句号；两句以上的说明每句都加。
- 同一个概念只用一个叫法：

| 用 | 不用 | 说明 |
|---|---|---|
| 导师 | 教授、老师 | 称呼某一位时可以写"张老师"；"教授"只作职称 |
| 邮件 | 单用的"信" | "写信、发信、收信、回信、信件样式"这些固定说法保留 |
| 回信 | 回复邮件 | 导师发来的邮件；动作用"回复"，如"已回复""回复率" |
| 首封、追问 | 第一封、跟进 | |
| 候选导师 | 候选人 | 标签和按钮上可以简写为"候选" |
| 后台工作 | 后台任务 | "任务"只指发信任务 |
| 待处理 | 需处理、需要处理 | |
| 发送前检查 | 发送前核对 | |

## 样式

### 风格

圆润、温和：暖灰的窗口底色上放一张白色的内容页。按钮、行、信件气泡都是圆角，分段控件、标签和搜索框是胶囊形。少用分割线，靠底色分层次。菜单、面板和弹窗浮在页面上，用柔和的阴影加一圈分割线色的细边；弹窗在手机上占满屏幕。

### 颜色

变量名沿用 shadcn/ui 的约定，另加了几个它没有的。深色模式跟随系统，也可以在设置里固定为浅色或深色。

| 变量 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| `--sidebar` | 窗口底色，侧边栏在它上面 | `#f3f0ee` | `#141110` |
| `--background` | 内容页、菜单、面板 | `#ffffff` | `#1d1a18` |
| `--foreground` | 正文 | `#292524` | `#ede8e4` |
| `--muted-foreground` | 次要文字 | `#6f6762` | `#aba29c` |
| `--faint` | 提示文字、时间 | `#a39b95` | `#7a716b` |
| `--muted` | 输入区、标签、次要按钮、悬停、草稿纸面 | `#f6f3f1` | `#26211e` |
| `--press` | 在 `--muted` 上悬停和按下 | `#ece7e4` | `#302a26` |
| `--border` | 分割线 | `#ece7e3` | `#2e2825` |
| `--input` | 复选框描边；深色下分段控件的选中项 | `#ddd6d1` | `#3f3733` |
| `--primary` | 主按钮、勾选、进度；焦点框 `--ring` 同色 | `#991b1b` | `#c13b3b` |
| `--primary-hover` | 主按钮悬停 | `#7f1d1d` | `#d04a48` |
| `--primary-foreground` | 主按钮上的字 | `#ffffff` | `#ffffff` |
| `--brand-text` | 品牌色的字：当前导航、AI 按钮、链接 | `#991b1b` | `#f1958c` |
| `--selected` | 选中的行、当前会话、AI 按钮底色 | `#fbeeec` | `#33201e` |
| `--mine` | 自己发出的信 | `#fbeeec` | `#2c2321` |
| `--unread` | 新回信的红点和数字 | `#e5383b` | `#ff5b52` |
| `--info` | 已联系 | `#3f6aa8` | `#88a9dd` |

| `--avatar-1` 到 `--avatar-5` | 头像底色，按导师轮换 | `#f6e2de` `#f3e8d5` `#e2e8f2` `#e3eedf` `#ece3f1` | `#3d2624` `#382d1e` `#232a3a` `#243122` `#302638` |

- 标签有 8 种预设颜色：`#991b1b` `#c2410c` `#985a0c` `#2c7a4f` `#0e7490` `#3f6aa8` `#7e22ce` `#6f6762`。字用标签色混 35% 正文色，底色用标签色的 14%，同一个标签在浅色和深色下都清楚。
- 品牌深红沿用 V2，只用在主按钮、当前位置、选中和进度上。匹配度这类数据用中性色，免得一排红条看着像警告。
- 深色模式不是简单反色：底色是带暖调的近黑，品牌色提亮；大面积的底色（比如自己发出的信）用暖灰，不用暗红。

### 字体

- 用系统字体：macOS 上是苹方，Windows 上是微软雅黑 UI，英文和数字用系统的无衬线字体。不随应用打包字体：一套中文字体十几 MB，违背"轻快"；系统字体在各自平台上也显示得最清楚。
- 字号：正文 15px，次要 13px，最小 12px，页面标题 24px，区块标题 17px。数字用等宽数字，列表里的数字能对齐。

### 尺寸

- 圆角：8px（复选框、行内标记），12px（按钮、行），16px（卡片、菜单、面板），20px（内容页）；信件气泡 18px，发信人一侧的下角收成 6px；分段控件、标签和搜索框用全圆角。
- 侧边栏宽 228px；导师表格每行 62px；手机上能点的地方至少 40px 高。
- 图标用线条图标，18px，描边 1.6px。AI 相关的按钮都用四角星图标，和应用图标呼应。

### 滚动条

自己画：细、圆角、轨道透明，滑块用正文色的 20%，悬停时加深，跟着深浅模式变。用标准的 `scrollbar-width` 和 `scrollbar-color`；WebKit（macOS 的 WKWebView、iOS Safari）另用 `::-webkit-scrollbar` 写同样的样式。

### 动效

- 只用来回应操作：菜单和面板淡入，批量操作条升起，提醒滑入，时长 150–250ms。
- 系统开了"减少动态效果"时不播放动画。

### 应用图标

- 深红渐变（`#b52626` 到 `#861717`）的圆角方块上是 V2 的白色线条信封，右上角加一大一小两颗瘦高的四角星，表示 AI 帮你写信。信封的线条在大星旁留出均匀的间隙，以圆头收住，不被星星切断。
- 源文件是 [icon.svg](icon.svg)。打包时按各平台的规范生成各个尺寸，macOS 的图标要留出系统规定的边距。
