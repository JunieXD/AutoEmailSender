# Auto Email Sender 导师导入契约 v1

## 工作簿结构

- 文件扩展名必须是 `.xlsx`，内容必须是合法的 Office Open XML 工作簿。
- 第一个且活动的工作表必须命名为 `Professors`；系统只读取活动工作表。
- Skill 生成的表头必须位于第 1 行，不得使用中文别名、合并表头或重复列名。
- 默认安全模式按顺序输出 10 列：`name,email,title,university,school,department,research_direction,recent_papers,profile_url,source_url`。
- 完整模式再依次追加 `tags,personal_note`。不要插入其他列。
- 数据从第 2 行开始。空单元格保持真正的空值，不要写 `None`、`null`、`N/A`、`未知`、`暂无`、`无` 或 `-`。
- `Professors` 中不得包含公式。相同邮箱不得出现两次；系统本身会让后出现的记录覆盖前一条，但 Skill 必须提前消除这种歧义。
- 应用导入可省略 `Needs Review` 和 `Sources`，但本 Skill 的抓取交付和独立校验要求这两张表始终存在。没有待复核人员时保留空表和表头；`Sources` 至少包含一个实际访问、跳过或失败的入口，并覆盖记录引用的 URL。
- 随附读取器限制：文件不超过 20 MiB、ZIP 解压总量不超过 64 MiB、每表最多 100000 条数据和 12 列。超出时拆分候选 JSON 分批交付，不提高限制硬读。

## 字段规则

| 字段 | 必填 | 格式与限制 |
| --- | --- | --- |
| `name` | 是 | 导师页面显示的原始姓名；去除首尾空白；最长 255 字符；不得以 `#` 或 `示例：` 开头；不要翻译、拼音化或附加职称。 |
| `email` | 是 | 最终必须是小写合法邮箱，最长 255 字符。允许还原 HTML `&#64;`、全角 `＠/．`、`[at]/(at)`、`[dot]/(dot)`、字母数字之间的中文“点”、空白和连续域名点。必须恰好一个 `@`；本地部分只允许 ASCII 字母、数字、`.`、`_`、`%`、`+`、`-`；域名至少两段，标签合法，末级域名为至少两个字母。不得猜测。 |
| `title` | 否 | 只能是：`教授`、`副教授`、`助理教授`、`讲师`、`研究员`、`副研究员`、`助理研究员`、`特聘研究员`。`Professor`、`Teaching Professor`、`Professor of Practice`→`教授`，`Associate Professor`→`副教授`，`Assistant Professor`→`助理教授`，`Lecturer`、`Continuing Lecturer`、`Senior Lecturer`→`讲师`。先检查完整原职称中的排除标记，再做别名或子串映射：工程师/高工、实验师、技师、助教、编辑、博士后、退休、荣休、名誉、访问、客座以及 `Engineer`、`Emeritus/Emerita`、`Honorary`、`Visiting`、`Retired`、`Postdoctoral/Postdoc` 默认不导入。因此 `教授级高级工程师`、`Professor Emeritus` 和 `Visiting Associate Professor` 都不能截取成受支持职称。英文排除标记按完整单词匹配，`Professor of Electrical Engineering` 仍可正常映射为教授。`博导/博士生导师`是导师资格而不是职称，单独出现时留空。无法可靠映射的职称留空。最长 255 字符。 |
| `university` | 否 | 学校正式名称，保留页面原文；最长 255 字符。 |
| `school` | 否 | 学院、研究院或单位正式名称，保留页面原文；最长 255 字符。不要与 `department` 重复填充。 |
| `department` | 否 | 系、所、中心或具体部门，保留页面原文；最长 255 字符。 |
| `research_direction` | 否 | 多个明确方向使用中文分号 `；` 连接，例如 `大语言模型；智能体`。不要使用英文分号、竖线或换行作为最终分隔符；不要把整段个人简介复制进来。 |
| `recent_papers` | 否 | 最多 8 篇，保持论文标题原文并去重，最终使用竖线 `|` 分隔，例如 `Paper A|Paper B`。只收录页面明确归属于该导师的近期或代表论文；不要混入作者、期刊、摘要或猜测的论文。单篇标题若自身包含 `|`、中英文分号或换行，系统没有转义机制，不能无损表示；省略该篇并写入复核说明。 |
| `profile_url` | 否 | 导师个人详情页的绝对 `http/https` URL，最长 500 字符，不得包含用户名或密码。列表页不是个人主页，应留空而不是误填。 |
| `source_url` | Skill 必填 | 支持该行信息的确切官方页面绝对 URL，最长 500 字符，通常是个人主页；若信息只来自列表页则填写列表页。 |
| `tags` | 否 | 多个标签最终使用中文分号 `；` 分隔，每个标签最长 64 字符并去重。抓取时默认留空。导入已有导师时，非空标签会替换其标签集合，空标签会保留现有标签。 |
| `personal_note` | 否 | 最长 10,000 字符，仅用于用户自己的私人备注。不得把抓取证据、页面摘要或联系方式写入此字段。默认安全模式省略这一列，因为完整模式中的空值会清空相同邮箱导师的已有备注。 |

## 导入行为

- 每一行只有在 `name` 和规范化后的合法 `email` 均存在时才有效；无效行会计入失败数。
- 邮箱会转为小写，并按邮箱更新或新增导师；更新会覆盖姓名、职称、学校、学院、院系、研究方向、论文和两个 URL，并恢复回收站记录。
- 省略 `personal_note` 列会保留已有备注；包含该列则无论为空还是非空都会覆盖已有备注。
- 非空 `tags` 会按文件顺序创建或替换导师标签；空标签不会清空已有标签。
- 职称不在白名单时系统会保存为空，而不是保留原字符串。
- `recent_papers` 会按 `|`、中英文分号或换行拆分、去重，并只保留前 8 篇；Skill 必须在生成前完成选择，不依赖静默截断。
- 任何以公式形式存储的单元格都不允许交付。生成器把所有抓取内容写成显式文本，避免公式注入。

机器可读版本见 `assets/professor-import-contract.v1.json`。该文件必须通过仓库测试与后端常量保持一致。
