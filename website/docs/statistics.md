# 统计面板

统计面板汇总导师资料、联系进度和 Token 用量，帮助你了解当前工作情况。

## 导师概览

导师概览展示：

- 导师总数、已匹配导师和高匹配导师数量
- 导师资料完整度
- 匹配分数分布
- 学校和学院分布

资料完整度可以帮助你判断哪些导师缺少邮箱、研究方向或近期论文。匹配结果较少时，可先补全资料并重新分析。

![导师规模、资料完整度与匹配分布](/screenshots/docs/statistics/statistics-overview.png)

## 联系进度

联系进度展示：

- 已发送数量和联系覆盖率
- 已回复数量和回复率
- 每日发送趋势
- 学校或学院的联系效果
- 首次回复等待时间分布

院校对比可以按联系覆盖率或回复率排序。样本较少时，单个回复会明显影响比例，建议同时查看已发送数量。

启用多身份共享后，统计面板会合并共享组内的通信记录，并提示当前使用的统计范围。

![多身份共享下的联系进度与回复率](/screenshots/docs/statistics/statistics-contact-performance.png)

## Token 用量

Token 面板用于查看模型调用量和估算成本，包括：

- 不同日期的 Token 趋势
- 匹配分析、智能抓取、信息补全和草稿生成等功能分布
- 不同模型的用量排名
- 每条调用记录的输入、输出和缓存 Token

在模型配置中填写单价后，系统会估算费用。估算结果仅供参考，实际账单以模型服务商为准。

![Token 趋势、功能分布与模型用量](/screenshots/docs/statistics/statistics-token-usage.png)

## 筛选统计范围

可按时间、学校和学院缩小统计范围。切换筛选后，汇总数字和图表会一起更新；清除筛选即可恢复全部数据。

统计结果来自当前导师、任务和通信记录。删除、恢复或修改相关数据后，面板也会随之更新。
