# 社区导师库

社区导师库让同学们共享已经整理过的高校导师公开信息。你可以在软件内按学校和学院浏览、搜索、预览并导入，不需要重复爬取同一批官网页面。

数据和贡献记录公开保存在独立的 [GitHub 仓库](https://github.com/JunieXD/AutoEmailSender-MentorData)。软件只读取经过版本和完整性校验的发布数据，不需要登录 GitHub。

## 导入社区导师

1. 打开顶部导航中的“社区导师库”。
2. 从左侧选择学校和学院，然后点击“加载所选学院”。页面会提前计算人数，一次最多加载 2,000 位导师。
3. 按姓名、任一邮箱、任一当前任职或研究方向搜索；较长结果会自动分页。
4. 勾选导师并点击“预览并导入”。
5. 检查有差异的字段，确认后导入。

默认规则是：

- 新导师直接新增；
- 本地空字段由社区补全；
- 本地已有值不自动覆盖；
- 社区没有内容的字段不能用来清空本地资料；
- 本地和社区都改过的字段由你逐项选择；
- 预览后如果本地导师又被修改，旧预览会失效并提示重新预览；
- 本地回收站导师不会自动恢复；
- 标签、个人备注、任务、发送记录和匹配结果永远不会被导入。

同一位导师可能有多个当前邮箱或多个任职。页面会完整展示这些信息，默认导入主要邮箱和主要任职。

## 重复与邮箱匹配

邮箱只是第一次导入时的候选匹配线索，不是导师的永久 ID。建立关联后，软件使用稳定社区 ID 跟踪后续变化。

如果邮箱相同但姓名或学校不同，软件会要求你确认，因为这可能是双聘、调动、邮箱重新分配，也可能是错误数据。如果一个邮箱匹配多位本地导师，或本地导师已经关联另一条社区记录，软件会阻止自动导入。

## 退休、离职和撤销

导师退休、离职、去世、信息有争议或被社区撤销时，软件会显示醒目提醒和证据来源，但不会自动删除、归档或修改你的本地导师，也不会影响历史任务和通信记录。

## 贡献导师信息

贡献和反馈必须在系统浏览器中的 GitHub 完成，以 GitHub Issue 作者作为可追踪的数据来源。

### 按学校或学院批量贡献

在社区导师库页面点击“批量贡献学校/学院”，软件会带你进入导师管理页并显示操作提示：

1. 先抓取或导入该学校、学院的导师数据；
2. 使用学校或学院筛选，并点击表头“选择全部筛选结果”；
3. 在页面底部点击“生成共享包并投稿”。

软件会生成只包含社区允许的 10 个公开字段的 XLSX，不包含标签、个人备注、任务或通信数据，并同时打开 GitHub 批量投稿表。下载完成后把 XLSX 拖入表单并提交即可。

### 补充一位导师

单导师投稿是补漏入口。在导师编辑窗口点击“贡献到社区”，软件会把允许公开的职业字段复制到剪贴板并打开 GitHub 投稿表。粘贴、核对并提交即可。

### 反馈错误

在社区导师卡片点击“反馈错误”。软件会复制稳定导师 ID 和当前社区值，并打开反馈表。请补充新的高校官方证据。反馈不会直接修改数据，需要维护者确认是真错误、假反馈还是证据不足。

## 离线缓存与安全

每次打开页面时，软件都会自动检查社区目录更新。每个数据文件都有声明大小和 SHA-256，软件还会核对数据版本、最低应用版本、目录路径、学校与学院归属、文件字节数和哈希；只有完整验证成功的数据才进入本地缓存。网络不可用时，可以继续使用最后一次验证成功的缓存，并会在页面上持续明确提示。

缓存由软件自动管理：会保留当前和最近使用的数据，并自动清理旧版本或很久没用的学院数据，避免长期占满磁盘。被清理的学院数据会在下次选择时重新下载，不需要你手动整理缓存目录。
