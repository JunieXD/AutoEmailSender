# 社区导师库

社区导师库共享已经整理过的高校导师公开信息。你可以按学校和学院浏览、搜索、预览并导入，无需重复抓取同一批官网页面。

数据和贡献记录公开保存在独立的 [GitHub 仓库](https://github.com/JunieXD/AutoEmailSender-MentorData)。使用数据无需登录 GitHub，导入前会校验版本和完整性。

![按学校和学院浏览社区导师](/screenshots/docs/community/community-mentor-catalog.png)

## 导入社区导师

1. 打开顶部导航中的“社区导师库”。
2. 选择学校和学院并加载数据；每次最多加载 2,000 位导师。
3. 按姓名、邮箱、任职或研究方向搜索；需要时可选择全部筛选结果。
4. 勾选导师并点击“预览并导入”。
5. 检查有差异的字段，确认后导入。

![社区导师导入预览](/screenshots/docs/community/community-import-preview.png)

默认规则是：

- 新导师直接新增，本地空字段自动补全。
- 本地已有值不会覆盖，冲突字段由你选择。
- 不会清空本地资料或恢复回收站导师。
- 标签、备注、任务、发送记录和匹配结果永远不会导入。

预览后如果本地资料发生变化，需要重新预览。

预览区可以按差异类型、涉及字段和确认状态筛选。处理同一字段的多条冲突时，可批量选择“保留本地”或“采用社区”，再逐条检查特殊情况。

同一位导师可能有多个当前邮箱或多个任职。页面会完整展示这些信息，默认导入主要邮箱和主要任职。

## 重复与邮箱匹配

首次导入时用邮箱匹配；关联后用社区 ID 跟踪更新。

邮箱相同但姓名或学校不同时，软件会要求你确认。存在多重匹配或已有其他社区关联时，无法自动导入。

## 退休、离职和撤销

遇到退休、离职、去世、争议信息或撤销记录时，软件只显示提醒和证据，不会改动本地资料或历史记录。

## 贡献导师信息

贡献与纠错通过 GitHub 提交，便于追踪来源。

### 按学校或学院批量贡献

在社区导师库页面点击“批量贡献学校/学院”，软件会带你进入导师管理页并显示操作提示：

1. 先抓取或导入该学校、学院的导师数据；
2. 使用学校或学院筛选，并点击表头“选择全部筛选结果”；
3. 在页面底部点击“贡献到社区”。

软件会生成只含 10 个公开字段的 XLSX，不包含标签、备注、任务或通信数据。保存后会打开 GitHub 投稿表，把 XLSX 拖入表单并提交即可；取消保存时不会打开浏览器。

### 补充一位导师

在导师编辑窗口点击“贡献到社区”，软件会复制允许公开的职业字段并打开 GitHub 投稿表。粘贴、核对并提交即可。

### 反馈错误

在社区导师卡片点击“反馈错误”，软件会复制导师 ID 和当前数据并打开表单。请补充高校官网证据；反馈经维护者审核后才会修改数据。

## 离线缓存与安全

软件会自动检查更新并校验文件完整性。断网时仍可使用最近一次验证成功的缓存，页面会提示当前状态。

缓存会自动清理；再次打开已清理的学院时，软件会重新下载数据。
