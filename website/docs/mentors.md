# 导师管理

导师管理页用来准备和维护导师数据，是后续筛选、匹配分析、生成草稿和创建任务的基础。

## 智能抓取

智能抓取从学校官网搜集和整理导师信息。创建抓取任务时，填写学校、学院和起始页面地址即可。

抓取进度在任务中心查看。抓取结果先进入候选区，需要人工审核后才会正式入库。

适合抓取的页面通常满足以下条件：

- 学院或课题组的导师列表页
- 每位导师有独立详情页
- 页面中包含邮箱、研究方向、论文或个人主页链接

官网结构复杂时，抓取结果可能需要较多人工补充。

## 审核候选导师

智能抓取完成后，抓到的导师进入候选区，需要审核确认。审核时可对每条候选执行以下操作：

- **接受：** 将候选项导入正式导师库。
- **拒绝：** 放弃该候选项。
- **合并：** 与已有导师合并。

部分候选可能缺少邮箱——这通常是抓取时页面信息不全导致的。此类候选仍可审核，但导入后无法直接发送邮件，需要事后手动补全。

建议先处理明显重复和无效的条目，再补充关键字段，这样后续在首页筛选和创建任务时会更清晰。

## 导入导师

已有导师表格的话，可以直接导入。系统支持 CSV 和 XLSX 两种格式。

### 导入流程

1. 点击导入，选择 CSV 或 XLSX 文件。
2. 系统自动识别列名，对应到导师字段。
3. 预览导入结果，确认后写入导师库。

### 支持的列

导入文件可包含以下列（仅"姓名"为必填，其他可选）：

| 列名 | 对应字段 | 说明 |
|------|---------|------|
| 姓名 | name | 必填 |
| 邮箱 | email | 去重依据，多条记录邮箱相同时保留第一条 |
| 职称 | title | — |
| 学校 | university | — |
| 学院 | school | — |
| 系所 | department | — |
| 研究方向 | research_direction | — |
| 近期论文 | recent_papers | — |
| 个人主页 | profile_url | — |
| 来源链接 | source_url | — |
| 标签 | tags | 多个标签用逗号或分号分隔，不存在则自动创建 |

### 导入规则

- 第一行必须是列名，列名使用上表中的中文名称。
- 空行和以 `#` 开头的说明行自动跳过。
- 以"示例："开头的姓名行自动跳过（可通过这个机制在文件中添加示例）。
- 姓名或邮箱为空的行视为无效，计入失败数。
- 邮箱相同的多条记录只保留第一条。

## 手动维护

在导师管理页可以直接新增、编辑或删除导师信息。

重点维护以下字段：

- 姓名
- 邮箱
- 学校
- 学院或院系
- 职称
- 研究方向
- 近期论文或代表成果
- 个人主页

导师资料越完整，匹配分析越可靠。缺少邮箱无法直接发送邮件；缺少研究方向或论文则匹配分析缺少依据。

## 导师标签

导师标签用来分类和筛选导师，支持自定义名称和颜色。

标签的使用场景：

- **首页筛选：** 按标签快速筛选导师。
- **导入导出：** CSV/XLSX 导入时可在 tags 列指定标签，导出的数据也包含标签信息。
- **拖拽排序：** 已选标签支持拖拽调整顺序。
- **批量管理：** 从导师管理页批量分配或移除标签。

创建标签时可自定义名称、字体颜色和背景颜色。标签颜色会显示在首页、导师管理页和工作区等多个位置，方便快速识别。
