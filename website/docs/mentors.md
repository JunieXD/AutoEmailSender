# 导师管理

导师管理页用来准备和维护导师数据，是后续筛选、匹配分析、生成草稿和创建任务的基础。

## 智能抓取

智能抓取从学校官网搜集和整理导师信息。创建抓取任务时，填写学校、学院和起始页面地址即可。

抓取进度在任务中心查看。抓取结果先进入候选区，需要人工审核后才会正式入库。

适合抓取的页面通常满足以下条件：

- 学院或课题组的导师列表页
- 每位导师有独立详情页
- 页面中包含邮箱、研究方向、论文或个人主页链接

官网结构复杂时，抓取结果可能需要较多人工补充。

## 审核候选导师

智能抓取完成后，抓到的导师进入候选区，需要审核确认。审核时可对每条候选执行以下操作：

- **接受：** 将候选项导入正式导师库。
- **拒绝：** 放弃该候选项。
- **合并：** 与已有导师合并。

部分候选可能缺少邮箱——这通常是抓取时页面信息不全导致的。此类候选仍可审核，但导入后无法直接发送邮件，需要事后手动补全。

建议先处理明显重复和无效的条目，再补充关键字段，这样后续在首页筛选和创建任务时会更清晰。

## 导入导师

已有导师表格时，可以直接导入。系统支持 UTF-8 编码的 CSV 和 XLSX；也可以让 Codex 或 Claude Code 使用[导师抓取 Skill](./mentor-crawler-skill)，从学院官网生成经过校验的 XLSX。

### 导入流程

1. 点击导入，选择 CSV 或 XLSX 文件。
2. 系统自动识别列名，对应到导师字段。
3. 预览导入结果，确认后写入导师库。

### 支持的列

表头必须使用以下英文键名。前 10 列都必须存在；`tags` 和 `personal_note` 两列可省略。每条有效数据的 `name` 和 `email` 必须有值，其余单元格可以为空。

| 列名 | 内容与格式 |
| --- | --- |
| `name` | 导师姓名，最长 255 字符。 |
| `email` | 导师邮箱，最长 255 字符，也是新增或更新记录的唯一依据。系统会转为小写，并兼容常见的 `[at]`、`[dot]`、全角符号等混淆形式。 |
| `title` | 仅支持教授、副教授、助理教授、讲师、研究员、副研究员、助理研究员、特聘研究员；其他值会保存为空。 |
| `university` | 学校名称，最长 255 字符。 |
| `school` | 学院、研究院或单位名称，最长 255 字符。 |
| `department` | 系、所、中心或部门名称，最长 255 字符。 |
| `research_direction` | 研究方向；建议用中文分号 `；` 分隔多个方向。 |
| `recent_papers` | 论文标题使用 `|` 分隔；也兼容中英文分号和换行；去重后最多保留前 8 篇。 |
| `profile_url` | 导师个人主页，最长 500 字符。 |
| `source_url` | 信息来源页，最长 500 字符。 |
| `tags` | 可选。多个标签兼容中英文分号、竖线和逗号；单个标签最长 64 字符。非空值会替换同邮箱导师的标签，空值不会清空已有标签。 |
| `personal_note` | 可选。个人备注，最长 10,000 字符。只要文件中存在这一列，空单元格也会清空同邮箱导师的已有备注；省略整列才会保留备注。 |

### 导入规则

- XLSX 只读取当前活动工作表。官方模板和导师抓取 Skill 都把它命名为 `Professors`。
- 系统会查找同时包含前 10 个必需列名的表头行，因此官方模板顶部的说明行可以保留。自己制作文件时建议直接把表头放在第 1 行。
- 空行、首列以 `#` 开头的说明行，以及姓名以“示例：”开头的示例行会跳过。
- 姓名或规范化后的邮箱为空或无效时，该行计入失败数。
- 同一文件内邮箱重复时，后出现的记录覆盖前面的记录。导入已有邮箱会更新对应导师，并恢复回收站中的记录。
- 更新会覆盖导师基本字段和两个 URL。若要保护已有备注，务必省略 `personal_note` 整列。
- 不要在导入数据中使用公式。导师抓取 Skill 会把所有网页内容显式存为文本，避免公式注入。

从官网下载的模板包含全部 12 列。导师抓取 Skill 默认生成不含 `tags` 和 `personal_note` 的安全 10 列文件，并附带 `Needs Review` 与 `Sources` 工作表供人工核对；系统只会读取活动的 `Professors` 工作表。

## 手动维护

在导师管理页可以直接新增、编辑或删除导师信息。

重点维护以下字段：

- 姓名
- 邮箱
- 学校
- 学院或院系
- 职称
- 研究方向
- 近期论文或代表成果
- 个人主页

导师资料越完整，匹配分析越可靠。缺少邮箱无法直接发送邮件；缺少研究方向或论文则匹配分析缺少依据。

## 导师标签

导师标签用来分类和筛选导师，支持自定义名称和颜色。

标签的使用场景：

- **首页筛选：** 按标签快速筛选导师。
- **导入导出：** CSV/XLSX 导入时可在 tags 列指定标签，导出的数据也包含标签信息。
- **拖拽排序：** 已选标签支持拖拽调整顺序。
- **批量管理：** 从导师管理页批量分配或移除标签。

创建标签时可自定义名称、字体颜色和背景颜色。标签颜色会显示在首页、导师管理页和工作区等多个位置，方便快速识别。
