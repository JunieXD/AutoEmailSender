# 个人中心

在个人中心管理发件身份、材料、模板、模型和应用设置。

## 发件身份

一套发件身份对应一个发信邮箱和一个回复检测邮箱。

主要配置项：

- **发件人姓名和邮箱：** 导师收到邮件时看到的发件信息。
- **SMTP 主机、端口和授权码：** 发送邮件所用。
- **IMAP 主机、端口和授权码：** 同步已发送邮件和导师回复所用。

SMTP 和 IMAP 填写的是授权码，而非邮箱登录密码。163 和 QQ 邮箱可参考[首次配置中的邮箱授权码教程](./first-run#mail-authorization-code)。

保存后请分别测试 SMTP 和 IMAP。失败时，依次检查授权码、服务器地址、端口和邮箱服务商的第三方客户端设置。

发送日期、时间窗口和窗口内发送数量在创建任务时设置，与发件身份无关。

## 多身份共享

多个发件身份可以加入同一个共享组。共享后，应用会合并这些身份与同一位导师的通信记录，避免重复联系。

每个共享组还需要选择一个“匹配依据身份”。批量匹配会统一使用该身份的默认材料，因此应确保它已经设置主材料。

共享只影响通信展示和匹配依据，不会共享邮箱授权码，也不会自动改变发件身份。

## 材料与模板

两类材料用途不同：

- **默认材料：** 用于匹配分析，建议选择简历、研究计划或个人陈述。
- **AI 参考材料：** 在任务或工作区中选择，只用于生成和改写草稿。

默认邮件模板包含主题和正文。正文可使用以下占位符：

```
{{name}}                导师姓名
{{email}}               导师邮箱
{{title}}               导师职称
{{university}}          导师学校
{{school}}              导师学院
{{research_direction}}  导师研究方向
{{sender_name}}         发件人姓名
{{sender_email}}        发件邮箱
```

模板只生成初稿，发送前请在工作区检查。模板更新后，已经生成的草稿不会自动改变；需要时可在任务详情中重新套用。

## 模型配置

模型用于匹配分析、信息补全和草稿生成，支持 OpenAI 兼容接口。

建议流程：

1. 填写 API Base URL、API Key 和模型名并保存。
2. 获取模型列表并测试连接。
3. 将常用配置设为默认模型。

尚未选定服务时，可参考[首次配置](./first-run#llm-configuration)中的 DeepSeek 示例。

## 其他设置

### 草稿改写偏好

可设置改写强度、语气、正式程度、长度、具体程度和模板保留方式，也可填写自定义要求。这些设置会作为 AI 改写的默认偏好，不会覆盖系统安全规则。

“意向研究方向”会作为匹配分析的补充依据。内容应简短明确，避免粘贴整份申请材料。

### 运行参数

可调整匹配分析、智能抓取、信息补全和草稿生成的并发数与检查间隔。数值越高，对模型接口、网络和电脑资源的压力越大；没有明确需要时建议保留默认值。

### 桌面应用

Windows 安装版可以设置开机自启动。系统托盘不可用时，也可以从个人中心完全退出桌面应用。

## 命令行与 Agent

Windows 和 Apple Silicon Mac 桌面版可以启用命令行与 Agent 支持。

启用后，应用会安装本地命令行，并可为检测到的 Agent 安装官方操作说明。Agent 可以查询导师、筛选数据、管理任务和打开对应界面；真实发送等高风险操作仍需要明确确认。

软件升级时会自动更新已安装的支持文件。关闭此功能会卸载命令行和官方 Skill，已经打开的 Agent 可能需要重启。

## 测试写信

完成发件身份、材料、模板和模型配置后，给自己发送一封测试邮件。测试写信只验证配置，不会创建导师任务。

## Token 用量

个人中心会记录模型调用量，包括：

- 调用时间和模型配置
- 输入、输出、缓存和合计 Token
- 匹配分析、智能抓取、信息补全、草稿生成和写信测试等来源
- 按日期、功能和模型统计的图表

填写每百万 Token 的模型单价后，系统会估算 API 费用。统计面板也会展示相同数据的汇总视图。

## 诊断日志

遇到启动、抓取或后台任务问题时，可以在“诊断日志”中：

- 查看应用和后端日志摘要。
- 导出诊断日志交给开发者排查。
- 选择抓取任务并单独导出抓取日志。
- 清空本地界面日志。

日志可能包含任务名称、网址和错误信息。提交前请检查内容，不要公开邮箱授权码、API Key 或个人材料。
