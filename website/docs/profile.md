# 个人配置

个人页集中管理发件身份、申请材料、邮件模板、模型配置和其他辅助设置。第一次使用时，大部分准备工作都在这里完成。

## 发件身份

发件身份指定了发信邮箱和回复检测邮箱。

主要配置项：

- **发件人姓名和邮箱：** 导师收到邮件时看到的发件信息。
- **SMTP 主机、端口和密码：** 发送邮件所用。
- **IMAP 主机、端口和密码：** 检测导师回复所用。

SMTP 和 IMAP 填写的是授权码，而非邮箱登录密码。在邮箱官网的设置、账户安全或客户端授权页面中开启服务后即可获取。找不到入口时，可以直接搜索「邮箱名 + 授权码」。

保存身份后立即测试 SMTP 和 IMAP。测试失败时，优先检查授权码、服务器地址、端口和邮箱服务商的第三方客户端设置。

发送日期、时间窗口和窗口内发送数量在创建任务时设置，与发件身份无关。

## 材料与模板

材料和模板直接影响匹配分析和草稿生成的质量。

主材料选择简历、研究计划或个人陈述。系统将主材料作为匹配和写信的核心参考。

默认邮件模板包含主题和正文。正文可使用以下占位符：

```
{{name}}            导师姓名
{{email}}           导师邮箱
{{title}}           导师职称
{{university}}      导师学校
{{school}}          导师学院
{{research_direction}}  导师研究方向
{{sender_name}}     发件人姓名
{{sender_email}}    发件邮箱
```

模板生成的是初稿，不代表最终发送内容。发送前必须在工作区逐封审核。

## 模型配置

模型配置为匹配分析和邮件生成提供 LLM 能力。系统使用 OpenAI 兼容接口，支持所有兼容该格式的模型服务。

建议流程：

1. 填写 API Base URL、API Key 和模型名称。
2. 保存模型配置。
3. 获取模型列表，确认接口可访问。
4. 测试模型，确认返回结果正常。
5. 将常用配置设为默认模型。

尚未选定服务的话，建议先从 [DeepSeek API](https://platform.deepseek.com/) 开始：

- **API Base URL：** `https://api.deepseek.com`
- **模型名称：** `deepseek-v4-flash`
- **API Key：** 在 DeepSeek 平台申请

## 测试写信

完成发件身份、材料、模板和模型配置后，进入测试写信页给自己发送一封测试邮件。测试通过后再开始批量联系导师。

测试写信仅验证配置，不会创建导师任务。

## Token 用量

个人页提供 Token 用量追踪，帮助你了解和控制 API 调用成本。

### 用量列表

以表格形式展示所有 Token 消耗记录，每条记录包含：

- 消耗时间
- 关联的模型配置
- Token 数量（输入/输出/合计）
- 来源功能（匹配分析、智能抓取、草稿生成等）

### 按功能拆分

用量可按照来源功能类型筛选，支持的分类：

| 来源 | 说明 |
|------|------|
| 匹配分析 | 分析导师与材料匹配度的消耗 |
| 智能抓取 | 爬取导师信息的消耗 |
| 草稿生成 | 生成邮件草稿的消耗 |
| 批量草稿 | 批量生成草稿的消耗 |
| 写信测试 | 测试写信页的消耗 |
| 其他 | 其他场景的消耗 |

### 用量图表

支持按日查看 Token 消耗趋势，可选择时间范围，直观了解每天的用量变化。

### 成本估算

用量数据结合模型价格后可以估算 API 调用成本。在模型配置中填写模型的价格信息（每百万 Token 单价），系统自动计算预估费用。
