# 个人中心

在个人中心设置发件身份、材料、模板和模型。

## 发件身份

一套发件身份对应一个发信邮箱和一个回复检测邮箱。

主要配置项：

- **发件人姓名和邮箱：** 导师收到邮件时看到的发件信息。
- **SMTP 主机、端口和密码：** 发送邮件所用。
- **IMAP 主机、端口和密码：** 检测导师回复所用。

SMTP 和 IMAP 填写的是授权码，而非邮箱登录密码。在邮箱官网的设置、账户安全或客户端授权页面中开启服务后即可获取。找不到入口时，可以直接搜索「邮箱名 + 授权码」。

保存后请测试 SMTP 和 IMAP。失败时，依次检查授权码、服务器地址、端口和邮箱服务商的第三方客户端设置。

发送日期、时间窗口和窗口内发送数量在创建任务时设置，与发件身份无关。

## 材料与模板

两类材料用途不同：

- **默认材料：** 用于匹配分析，建议选择简历、研究计划或个人陈述。
- **AI 参考材料：** 在任务或工作区中选择，只用于生成和改写草稿。

默认邮件模板包含主题和正文。正文可使用以下占位符：

```
{{name}}            导师姓名
{{email}}           导师邮箱
{{title}}           导师职称
{{university}}      导师学校
{{school}}          导师学院
{{research_direction}}  导师研究方向
{{sender_name}}     发件人姓名
{{sender_email}}    发件邮箱
```

模板只生成初稿，发送前请在工作区逐封检查。

## 模型配置

模型用于匹配分析和生成邮件，支持 OpenAI 兼容接口。

建议流程：

1. 填写 API Base URL、API Key 和模型名并保存。
2. 获取模型列表并测试连接。
3. 将常用配置设为默认模型。

尚未选定服务时，可参考[首次配置](./first-run#_2-配置模型)中的 DeepSeek 示例。

## 测试写信

完成发件身份、材料、模板和模型配置后，给自己发送一封测试邮件。测试写信只验证配置，不会创建导师任务。

## Token 用量

个人中心会记录 Token 用量，帮助你了解 API 调用成本。

### 用量列表

用量列表显示：

- 消耗时间
- 关联的模型配置
- Token 数量（输入/输出/合计）
- 来源功能（匹配分析、智能抓取、草稿生成等）

### 按功能拆分

用量可按照来源功能类型筛选，支持的分类：

| 来源 | 说明 |
|------|------|
| 匹配分析 | 分析导师与材料匹配度的消耗 |
| 智能抓取 | 抓取导师信息的消耗 |
| 草稿生成 | 生成邮件草稿的消耗 |
| 批量草稿 | 批量生成草稿的消耗 |
| 写信测试 | 测试写信页的消耗 |
| 其他 | 其他场景的消耗 |

### 用量图表

可按日期和时间范围查看 Token 用量趋势。

### 成本估算

填写每百万 Token 的模型单价后，系统会估算 API 费用。
