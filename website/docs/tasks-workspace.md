# 任务与工作区

选好导师之后，审核、发送和追踪都在这里完成。

## 创建任务

在应用首页选择导师后创建联系任务。创建任务时确认：

- 目标导师
- 发件身份
- 模型配置
- 发送方式（立即发送或定时发送）
- 定时发送的时间窗口和数量限制

尚未完成首次配置时，请先到个人中心设置发件身份、模型、材料和模板。

## 发送设置

发送节奏在创建任务时设定，不在发件身份中设定。

两种发送方式：

- **立即发送：** 任务创建后进入发送流程，适合少量导师或需要逐封确认的场景。
- **定时发送：** 设置日期、时间窗口和每日数量，系统会按计划发送。

选择定时发送时，至少填写发送日期、开始时间、结束时间和窗口内发送数量。

## 工作区审核

工作区展示匹配结果、邮件草稿和发送状态。

匹配分析使用个人中心的默认材料。工作区选择的 AI 参考材料只用于生成和改写草稿。

发送前请逐封检查：

- 导师姓名和邮箱
- 邮件主题
- 正文是否贴合导师方向
- 是否有明显模板痕迹
- 附件和材料
- 发送时间

## 批量草稿生成

创建任务时选择多位导师，系统会在后台生成匹配分析和邮件草稿，进度可在任务中心查看。

草稿使用个人中心的默认模板和模型。某位导师生成失败时，只需单独处理，不影响其他导师。

## 任务中心

任务中心查看所有后台任务和批量任务，包括：

- 批量发送任务
- 智能抓取任务
- 匹配分析任务

可在任务中心查看进度，并按状态暂停、恢复、重试或停止任务。

## 回复追踪

系统通过 IMAP 自动检测导师回复，并更新任务状态。检测不到回复时，请到个人中心测试 IMAP。
