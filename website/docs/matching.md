# 匹配分析

匹配分析帮助你判断导师与材料的匹配程度。它不预测录取概率，也不能替代你自己的判断。

## 分析依据

匹配分析参考以下方面：

- 你的主材料
- 导师研究方向
- 导师近期论文
- 学校、学院和职称等背景信息
- 当前选择的模型配置

导师缺少研究方向和近期论文时，系统会提示资料不足，无法完成分析。

## 如何发起

在首页对单个或多个导师发起匹配分析。批量分析会生成后台任务，进度在任务中心查看。

分析完成后，首页和工作区展示匹配结果，供你决定联系优先级。

## 如何使用结果

匹配结果用作排序和筛选依据，而非唯一判断标准。

重点关注：

- 匹配分数
- 匹配理由
- 与哪些研究方向契合
- 邮件中可强调的个人经历
- 风险点或不匹配之处

结果明显偏离实际时，回到个人页检查主材料和模型配置，或去导师管理页补充导师资料。
