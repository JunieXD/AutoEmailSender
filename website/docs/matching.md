# 匹配分析

匹配分析帮助你判断导师与个人中心默认材料的匹配程度。它不预测录取概率，也不能替代你的判断。

## 分析依据

匹配分析参考以下方面：

- 个人中心当前默认材料
- 导师研究方向
- 导师近期论文
- 学校、学院和职称等背景信息
- 当前选择的模型配置

研究方向和近期论文都为空时，系统无法完成分析。

## 开始分析

在应用首页选择一位或多位导师开始分析。批量任务的进度可在任务中心查看，结果会显示在应用首页和工作区。

匹配分析使用个人中心的默认材料；任务中选择的 AI 参考材料只用于生成草稿。

## 如何使用结果

匹配结果用作排序和筛选依据，而非唯一判断标准。

重点关注：

- 匹配分数
- 匹配理由
- 与哪些研究方向契合
- 邮件中可强调的个人经历
- 风险点或不匹配之处

结果明显偏离实际时，请到个人中心检查默认材料和模型配置，或到导师管理页补充资料。
