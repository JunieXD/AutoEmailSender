# 快速开始

Auto Email Sender 是一个本地运行的导师联系工具。桌面版开箱即用，无需安装 Python、Node.js 等开发工具。

## 下载安装

请从 [GitHub Releases](https://github.com/JunieXD/AutoEmailSender/releases) 下载 Windows 或 Apple Silicon macOS 安装包。Intel Mac 暂无安装包；首次运行时请确认安装包来自本项目。详细步骤和安全提示见[安装桌面版](./install)。

## 基本流程

第一次打开应用，按系统内的「首次上手引导」完成配置：

1. [创建发件身份](./first-run#_1-创建发件身份)：填写发件人、邮箱、SMTP 和 IMAP。
2. [选择模型](./first-run#_2-配置模型)：配置 OpenAI 兼容模型。
3. [准备材料](./first-run#_3-准备材料和邮件模板)：上传默认材料并设置邮件模板。
4. [发送测试邮件](./first-run#_4-发送测试邮件)：检查邮箱、模板、附件和模型配置。
5. [补充导师](./first-run#_5-补充导师)：抓取、导入或手动添加导师。
6. [创建首个任务](./first-run#_6-创建首个任务)：选择导师并生成联系任务。

完成首次配置后，日常使用流程：

1. 筛选目标导师并查看匹配情况。
2. 创建联系任务。
3. 在工作区检查并修改草稿。
4. 发送邮件并追踪回复。
