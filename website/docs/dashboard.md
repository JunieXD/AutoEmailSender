# 应用首页

应用首页用于筛选导师、查看匹配度和创建任务。

## 筛选导师

使用搜索和筛选条件快速找到目标导师。

### 关键词搜索

可按姓名、学校、学院、系所、职称、研究方向和标签搜索，默认搜索全部字段。

### 匹配度筛选

设置匹配度最低分，筛掉低分导师。0 分等同于不限制。

### 联系状态筛选

按导师的联系状态筛选：

| 状态 | 含义 |
|------|------|
| 未开始 | 尚未创建任何联系任务 |
| 准备中 | 已创建任务，正在生成匹配分析或草稿 |
| 待发送 | 草稿已生成，等待发送 |
| 已联系 | 邮件已发送 |
| 已回复 | 导师已回复 |
| 失败 | 发送失败或流程异常 |

### 其他筛选

还可按学校、学院、标签、职称和系所缩小范围。多个已选条件会同时生效。

### 重置筛选

点击“重置”清空全部条件，恢复默认视图。

## 筛选状态提示

筛选栏会显示已启用的条件数和结果数。

## 排序

导师列表默认按匹配度从高到低排序，未分析匹配度的导师排在最末。

## 快速操作

在导师卡片上可以直接：

- 发起匹配分析
- 创建联系任务
- 查看已有任务
