# 首页

首页是日常使用的主要入口，集中了导师筛选、匹配度查看和任务创建功能。

## 筛选导师

首页提供多种筛选维度，帮助你从导师库中快速定位目标导师。

### 关键词搜索

在搜索框输入关键词，系统按已选的搜索范围进行匹配。支持的搜索范围：

- **姓名：** 匹配导师姓名
- **学校：** 匹配学校名称
- **学院：** 匹配学院名称
- **系所：** 匹配系所名称
- **职称：** 匹配职称
- **研究方向：** 匹配研究方向文本
- **标签：** 匹配已分配的标签名称

搜索范围可自由勾选，默认全选。

### 匹配度筛选

设置匹配度最低分，筛掉低分导师。0 分等同于不限制。

### 联系状态筛选

按导师的联系状态筛选：

| 状态 | 含义 |
|------|------|
| 未开始 | 尚未创建任何联系任务 |
| 准备中 | 已创建任务，正在生成匹配分析或草稿 |
| 待发送 | 草稿已生成，等待发送 |
| 已联系 | 邮件已发送 |
| 已回复 | 导师已回复 |
| 失败 | 发送失败或流程异常 |

### 学校与学院筛选

按学校-学院组合筛选。已选中的学校和学院会同时生效。

### 标签筛选

按自定义导师标签筛选。勾选一个或多个标签后，只展示具有这些标签的导师。

### 职称与系所筛选

按职称或系所进一步缩小范围。

### 重置筛选

点击重置按钮清空所有筛选条件，恢复默认视图。

## 筛选状态提示

筛选栏上方显示当前激活的筛选条件数量和已匹配的导师数量，方便了解筛选效果。

## 排序

导师列表默认按匹配度从高到低排序，未分析匹配度的导师排在最末。

## 快速操作

在首页导师卡片上可以直接：

- 发起匹配分析
- 创建联系任务
- 查看已有任务
