# v2.6.0-beta.1（Beta 测试版）

> [!WARNING]
> 这是用于主动测试的非稳定版本，可能出现后台任务中断、资源占用升高或需要切回兼容模式等问题。请勿在没有备份的日常数据上直接试用。

## 测试版说明

- 本版本不会通过应用内“检查更新”提供，也不会成为 GitHub Latest；只面向从 GitHub Prerelease 手动下载安装的测试者。
- 测试版本地诊断只保存在电脑上，不会自动上传；只有主动导出 ZIP 并自行发送时才会离开本机。
- 发布前会完成双平台覆盖安装和每平台 10 分钟密集运行与故障测试，但不包含小时级连续运行验证；低频问题将通过后续更高测试版修复。

### 新增功能

- 桌面端“其他设置”新增“API + Worker 测试模式”和“单进程兼容模式”，保存后重启即可切换；本测试版默认使用 API + Worker 模式。
- 新增完全保存在本机的 Beta 诊断记录，可按最近 1 小时、24 小时、7 天或全部保留期导出；页面无法打开时也可从托盘或启动失败窗口导出。
- 批量任务审核支持把已有模板应用到选中的待处理任务；命令行与 Agent 也增强了导师搜索和批量操作能力。

### 体验优化

- 后台发送、邮件同步、批量草稿、匹配和智能抓取改由独立 Worker 执行，界面请求与后台工作不再共用一个进程。
- 导师列表、筛选、全选和统计页针对大规模数据进行了提速，导师较多时等待和内存占用更稳定。
- 切换运行模式前会检查正在发送的邮件和活跃任务，不能安全中断时会明确提示并继续等待。

### 问题修复

- 修复取消匹配任务后偶尔仍显示运行中，以及批量任务轮询期间列表短暂丢失的问题。
- 修复导出大量已选社区导师时可能遗漏部分导师，以及批量模板操作作用到错误任务的问题。
- 修复 Windows 后台进程退出、状态文件瞬时占用或旧进程残留时可能导致启动和退出失败的问题。
- 加固邮件发送与重发边界：极端中断导致发送结果不确定时不会自动重发同一封邮件。

## 测试重点

- 从稳定版 v2.5.4 覆盖安装后，确认原有设置、导师、材料、任务和发送记录都能正常使用。
- 在两种运行模式之间来回切换，测试“稍后重启”和“安全重启”，并观察 API 或 Worker 异常退出后的恢复与兼容模式回退。
- 分别运行定时发送、两类邮件同步、批量草稿、匹配分析和智能抓取，并尝试休眠唤醒、临时断网、快速退出和较长时间连续运行。
- 在健康运行和出现问题后各导出一份诊断包，确认导出成功且说明中的模式、版本和故障时间准确。
- 健康运行也请定期导出一份诊断包，避免样本只包含故障设备。

## 安装前备份

- 完全退出 Auto Email Sender，再复制整个数据目录：Windows 为 `%APPDATA%\auto-email-sender-desktop`，macOS 为 `~/Library/Application Support/auto-email-sender-desktop`。
- 本版本包含数据库迁移，首次启动会生成升级前备份；手动复制的数据目录仍应保留到测试结束。
- 建议先使用隔离数据和测试邮箱；如确需验证现有数据，请先确认收件人、定时任务和自动发送开关不会产生真实误发。

## 安装与覆盖升级

- Windows：从本 Prerelease 下载 `AutoEmailSender-Setup-2.6.0-beta.1.exe`，在保留现有数据的情况下覆盖安装。
- macOS Apple Silicon：从本 Prerelease 下载 `AutoEmailSender-2.6.0-beta.1-arm64.dmg` 并覆盖安装；Intel Mac 暂不支持。
- macOS 若首次打开被阻止，请前往“系统设置 > 隐私与安全性”选择“仍要打开”。

## 回退与诊断

- 如 API + Worker 测试模式不稳定，请在“其他设置”切换到“单进程兼容模式”并重启；这只切换同一版本的运行拓扑，不会降级数据库。
- 页面无法打开时，可从托盘或原生启动失败窗口导出 partial 诊断包。诊断包不包含数据库副本、邮件正文、附件、导师资料或凭据。
- 诊断包只会在你主动选择保存位置时导出，不会自动上传；如需反馈，可自行把导出的 ZIP 发给项目维护者。
- 邮件发送结果不确定时不会自动重发，也不要求用户确认投递结果或依赖发件箱记录。

## 自动更新隔离

- 稳定版客户端不会检测到本测试版；本测试版也不发布稳定通道使用的 `latest.yml`、`appcast.xml` 或差分包。
- 后续测试版使用新的、更高 prerelease 版本，不覆盖已经公开的安装包。

## 停止使用与取代

- 如果本版本被标记为“停止使用”，请停止继续测试并按公告导出最后一份诊断包。
- 修复版本会以更高的 Beta / RC 版本另行发布；旧资产保留用于审计，不会被替换。
