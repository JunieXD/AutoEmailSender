为每位导师，撰写一封专属邮件

Auto Email Sender 是帮助学生联系导师的桌面应用。它整理导师信息，分析研究方向的匹配度，并为每位导师起草邮件。每封邮件均经你确认后发出，回信自动归入对应导师。

  • 支持 Windows 和 macOS
  • 本地功能无需登录
  • 基于 GPL-3.0 开源

从查找导师到处理回信，一个应用即可完成

信息整理和邮件起草由应用完成；发送对象、内容和时间由你决定。

  1. 1

    查找导师

    输入学院官网或教师名录的网址，应用自动整理导师的邮箱、研究方向、近期论文和个人主页。整理结果先列为候选导师，由你逐一接受、并入已有导师或拒绝；登录后还可从导师库直接添加。

    • 整理过程可随时暂停、继续或重试
    • 自动标出疑似重复的导师
    • 可补全缺失的信息，也可导入表格

  2. 2

    分析匹配度并起草邮件

    AI 对照你的背景与导师的研究方向和论文，给出匹配度及理由。起草时以你的模板为基础，针对每位导师改写相关段落，改动之处逐一标出。

    • 可自行选择模型服务商
    • 模板支持占位符，可从 Word 导入
    • 发出前可由 AI 再次核对

  3. 3

    确认后定时发送

    批量生成首封，逐封批准后加入发送计划，按设定的时间分批发出，并可由多个邮箱轮流发送。发送前自动检查占位符、称呼和收件域名。

    • 未经你批准的邮件不会发出
    • 邮箱被限流时自动暂停，恢复后继续发送
    • 发送中途关闭应用，也不会重复发出

  4. 4

    处理回信和追问

    回信自动归入对应导师，AI 标出回信结果（有意向、无名额或拒绝），并提取待办事项。长时间未回复的导师，可向其发送追问。

    • 应用在后台运行时照常收信，收到回信即时通知
    • 统计页显示回复率和首次回复用时

由你做主

AI 仅提供建议和草稿，邮件和数据始终由你掌控。

  • 每封邮件均需你批准

    发送对象、内容和时间均由你决定，未经批准的邮件不会发出。

  • 数据保存在本机

    本地功能无需登录。使用需要服务器的功能前，应用会说明发送哪些数据、发往何处。

  • 源代码公开

    源代码以 GPL-3.0 许可证在 GitHub 公开，数据的处理方式任何人都可查验。

更多功能

  • 导师库

    登录后可从已整理的各校导师名录中直接添加导师。

  • 手机远程

    不在电脑旁时，可通过手机浏览器查看和处理。

  • 邮件追踪

    查看邮件的打开记录，结果仅供参考。

  • 云端备份

    端到端加密，服务器无法读取；更换电脑时可恢复数据。

  • Agent 接口

    AI 助手可通过命令行或 MCP 使用本应用，发信仍需你批准。

  • 多邮箱轮流发送

    可设置轮换方式，也可为导师指定发件邮箱。

  • 统计

    查看联系进度、回复情况和模型用量。

  • 信件样式

    可设置字体、字号、行距和段首缩进。
